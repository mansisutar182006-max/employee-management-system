# Employee Management System (Python CRUD)

This project is a simple Employee Management System developed using Python.

## Features
- Add Employee
- View Employees
- Search Employee
- Update Employee
- Delete Employee

## Technologies Used
- Python
- Object Oriented Programming (OOP)
- Dictionary Data Storage

## Project Structure
main.py – program entry point  
admin.py – admin operations  
emp.py – employee class  
datastore.py – data storage logic  
config.py – configuration file
